# Публикация SANMOLD на Cloudflare Pages

Сайт — статический HTML/CSS/JS, сборка не требуется.

1. Войдите в Cloudflare Dashboard → Workers & Pages.
2. Выберите Create → Pages → Connect to Git.
3. Авторизуйте GitHub и выберите репозиторий `evko-netizen/sanmold-website`.
4. Production branch: `main`.
5. Framework preset: `None`; build command: оставить пустым; output directory: `/` (корень репозитория, если интерфейс это поддерживает).
6. Deploy. Cloudflare выдаст адрес вида `<project>.pages.dev`.
7. Для своего домена: Pages → Custom domains → Set up a custom domain и следуйте инструкциям DNS.

## Перед запуском
- Проверьте контактные данные и содержание страниц.
- Замените демонстрационную CSS-иллюстрацию реальными материалами производства.
- Проверьте доступность GSAP CDN из целевых регионов.
- Настройте аналитику и политику обработки персональных данных перед добавлением формы, собирающей данные.
- Проверьте отображение на телефоне и в браузерах.

Форма заявки пока реализована через mailto: серверная отправка не подключена.
